# Meu Treino — primeira versão

## O que já funciona
- Treino de sábado com os seis exercícios do PDF.
- Cargas sugeridas por série conforme a planilha.
- Campos editáveis para carga e repetições.
- Marcação de séries concluídas e progresso.
- Cronômetro de descanso com atalhos de 1, 1:30 e 2 minutos.
- Salvamento local no navegador.
- Exportação e importação de backup JSON.
- Estrutura PWA para instalação na tela inicial e cache offline.

## Como publicar para obter um link
A publicação exige hospedagem HTTPS. Uma opção simples é GitHub Pages:
1. Crie uma conta ou entre no GitHub.
2. Crie um repositório público chamado `meu-treino`.
3. Envie os quatro arquivos desta pasta para a raiz do repositório.
4. Em Settings > Pages, selecione Deploy from a branch, escolha `main` e `/ (root)`, e salve.
5. O GitHub mostrará o endereço publicado. Abra esse endereço no celular.

No Android/Chrome: menu ⋮ > Instalar app ou Adicionar à tela inicial.
No iPhone/Safari: Compartilhar > Adicionar à Tela de Início.

## Importante
- Os dados são locais ao navegador/dispositivo. Não há login nem sincronização automática.
- Exporte um backup periodicamente e antes de limpar os dados do navegador.
- O PDF fornecido contém apenas o treino de sábado; os demais dias podem ser cadastrados depois.
- A publicação não foi feita automaticamente: é necessário criar/configurar a hospedagem.
